# Parallax Scrolling Website

A modern and immersive parallax scrolling website built with pure HTML, CSS, and JavaScript.

The website uses multiple layered images that move at different speeds while scrolling to create a smooth sense of depth and motion.

## ✨ Features

- Smooth parallax scrolling effects
- Multiple layered background elements
- Animated hills and foreground elements
- Smooth navigation between sections
- Active navigation link detection
- Responsive design for desktop, tablet, and mobile
- Clean modern typography
- Smooth hover animations
- About section with detailed parallax explanation
- Service section with feature cards
- Contact section with smooth navigation
- Lightweight implementation using vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- CSS Flexbox
- CSS Grid
- Responsive Media Queries
